# Curso de Python, videoaula 02: Programação Sequencial

> Repositório oficial das videoaulas do Curso de Python do canal Fabricio Curvello no YouTube.

## Sobre

Este é um dos **repositórios oficiais das videoaulas do Curso de Python** do canal [Fabricio Curvello no YouTube](https://www.youtube.com/@fabriciocurvello). O código é o mesmo apresentado nas aulas, para o aluno acompanhar, executar e modificar.

Assunto desta parte do curso: Variáveis, entrada de dados, operadores e formatação de texto.

## Arquivos

- `variaveis.py`: declaração e tipos de variáveis.
- `entrada_de_dados.py`: leitura de dados com `input()`.
- `operadores.py`: operadores aritméticos.
- `interpolacao_string*.py`: formatação de strings com `%`, `.format()` e **f-strings** (inteiros, decimais e CPF).
- `recursos.py`: outros recursos da linguagem.

## Tecnologias

- **Python 3**
- **PyCharm** (IDE usada nas videoaulas)

## Como executar

Com o [Python 3](https://www.python.org/downloads/) instalado:

```bash
git clone https://github.com/fabcurvello/CursoPythonVideoaulas02progSequencial.git
cd CursoPythonVideoaulas02progSequencial
python main.py
```

Para rodar outro exemplo, troque `main.py` pelo nome do arquivo. Também é possível abrir a pasta no PyCharm e executar pelo botão ▶.
